# fmt - Documentación generada con Doxygen

Esta documentación fue generada como parte del **Laboratorio 1 (IE0417)** sobre las bibliotecas [{fmt}](https://github.com/fmtlib/fmt), una biblioteca de C++ para formateo de texto rápido y seguro en cuanto a tipos.

- **Repositorio original:** https://github.com/fmtlib/fmt
- **Licencia:** MIT
- **Commit documentado:** `b039e624c02ae473280156235217f9e02792b055`

## Cómo navegar esta documentación

- La pestaña **Namespaces** lista los espacios de nombres del proyecto (principalmente `fmt`).
- La pestaña **Classes** lista todas las clases y estructuras, con sus miembros, herencia y colaboraciones.
- La pestaña **Files** permite explorar los archivos fuente (`include/fmt/*.h`, `src/*.cc`) con navegación cruzada de símbolos gracias a `SOURCE_BROWSER`.
- Los diagramas de llamadas y de clases se generan automáticamente mediante Graphviz cuando la estructura del código lo permite.

Esta configuración de Doxygen fue creada específicamente para este laboratorio y no corresponde a la documentación oficial del proyecto.
