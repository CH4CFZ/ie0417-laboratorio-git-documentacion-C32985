black.strings module

Simple formatting on strings. Further string formatting code is in trans.py.

black.strings.lines_with_leading_tabs_expanded(s: str) → list[str][fuente]

Splits string into lines and expands only leading tabs.

Black normalizes code indentation to four-space columns, so leading tabs in docstrings need the same width to keep relative indentation stable.

black.strings.char_width(char: str) → int[fuente]

Return the width of a single character as it would be displayed in a terminal or editor (which respects Unicode East Asian Width).

Full width characters are counted as 2, while half width characters are counted as 1. Also control characters are counted as 0.

black.strings.str_width(line_str: str) → int[fuente]

Return the width of line_str as it would be displayed in a terminal or editor (which respects Unicode East Asian Width).

You could utilize this function to determine, for example, if a string is too wide to display in a terminal or editor.

black.strings.count_chars_in_width(line_str: str, max_width: int) → int[fuente]
