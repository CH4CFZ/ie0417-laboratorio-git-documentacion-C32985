black.concurrency module

Formatting many files at once via multiprocessing. Contains entrypoint and utilities.

NOTE: this module is only imported if we need to format several files at once.

black.concurrency.maybe_use_uvloop() → AbstractEventLoop[fuente]

If our environment has uvloop or winloop installed we use it otherwise a normal asyncio eventloop is called as fallback.

This is called only from command-line entry points to avoid interfering with the parent process if Black is used as a library.

black.concurrency.cancel(tasks: Iterable[Future[Any]]) → None[fuente]

asyncio signal handler that cancels all tasks and reports to stderr.

black.concurrency.shutdown(loop: AbstractEventLoop) → None[fuente]

Cancel all pending tasks on loop, wait for them, and close the loop.

black.concurrency.reformat_many(sources: set[Path], fast: bool, write_back: WriteBack, mode: Mode, report: Report, workers: int | None, no_cache: bool = False) → None[fuente]

Reformat multiple files using a ProcessPoolExecutor.

async black.concurrency.schedule_formatting(sources: set[Path], fast: bool, write_back: WriteBack, mode: Mode, report: Report, loop: AbstractEventLoop, executor: Executor, no_cache: bool = False) → None[fuente]

Run formatting of sources in parallel using the provided executor.

(Use ProcessPoolExecutors for actual parallelism.)

write_back, fast, and mode options are passed to format_file_in_place().
