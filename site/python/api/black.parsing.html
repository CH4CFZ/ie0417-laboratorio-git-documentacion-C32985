exception black.parsing.SourceASTParseError[fuente]

Bases: Exception

Raised when the source file cannot be parsed by ast.parse().

This is not a bug in Black — Black’s lib2to3-based parser is more lenient than Python’s ast.parse(), so it may accept code that ast.parse() rejects. In blackd, this should be reported as a 400 Bad Request.
