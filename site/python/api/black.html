black.format_cell(src: str, *, fast: bool, mode: Mode) → str[fuente]

Format code in given cell of Jupyter notebook.

General idea is:

  • if cell has trailing semicolon, remove it;

  • if cell has IPython magics, mask them;

  • format cell;

  • reinstate IPython magics;

  • reinstate trailing semicolon (if originally present);

  • strip trailing newlines.

Cells with syntax errors will not be processed, as they could potentially be automagics or multi-line magics, which are currently not supported.

black.validate_metadata(nb: MutableMapping[str, Any]) → None[fuente]

If notebook is marked as non-Python, don’t format it.

All notebook metadata fields are optional, see https://nbformat.readthedocs.io/en/stable/format_description.html. So if a notebook has empty metadata, we will try to parse it anyway.

black.format_str(src_contents: str, *, mode: Mode, lines: Collection[tuple[int, int]] = ()) → str[fuente]

Reformat a string and return new contents.

mode determines formatting options, such as how many characters per line are allowed. Example:

>>> import black
>>> print(black.format_str("def f(arg:str='')->None:...", mode=black.Mode()))
def f(arg: str = "") -> None:
    ...

A more complex example:

>>> print(
...   black.format_str(
...     "def f(arg:str='')->None: hey",
...     mode=black.Mode(
...       target_versions={black.TargetVersion.PY36},
...       line_length=10,
...       string_normalization=False,
...       is_pyi=False,
...     ),
...   ),
... )
def f(
    arg: str = '',
) -> None:
    hey
